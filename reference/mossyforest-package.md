# mossyforest: Network Aware Stability Selection with Random Forests

An interpretable, network aware random forest feature selection
framework for high dimensional and correlated data. It combines module
stratified recursive feature elimination, shadow stability selection,
and 'TreeSHAP' (Tree SHapley Additive exPlanations) importance, with
modules either provided by the user or derived with 'WGCNA' (weighted
gene co expression network analysis). The default backend requires a
'Python' environment with 'scikit-learn', 'shap', and 'numpy', which can
be configured with mf_setup(). A pure 'R' backend based on 'ranger' is
also available.
